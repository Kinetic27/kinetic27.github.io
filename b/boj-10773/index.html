접근

해당 문제는 스택 자료구조만 알고있으면 간단하게 해결할 수 있다.
또한 파이썬의 리스트에는 내장으로 pop 명령어가 존재하기 때문에 이를 이용하면 된다.

정수가 "0"일 경우에 지울 수 있는 수가 있음을 보장하기 때문에 따로 검사하지 않고
0이 입력으로 들어오면 pop을 실행
그렇지 않다면 스택에 값을 넣어주면 끝이다.

코드

money = []

for _ in range(int(input())):
    n = int(input())
    
    if n == 0:
        money.pop()
    else:
        money.append(n)
        
print(sum(money))
